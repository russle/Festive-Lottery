# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please do NOT open a public issue. 

Instead, please send an authorized email to the maintainer or use GitHub's private vulnerability reporting feature if enabled.

### What is considered a vulnerability?
- Potential for unauthorized data access.
- Exploitable bugs in the lottery randomization logic.
- Leaks of private configuration or API keys.

We will acknowledge your report within 48 hours and provide a fix as soon as possible.
